# Zurely Documentation & Policies (`zurely-docs`)

This repository contains the official markdown documentation, legal policies, and organizational materials for **Zurely**—a digital tenancy platform based in Malaysia designed to streamline the creation, signing, stamping, and payment of tenancy agreements.

These documents are maintained in Markdown (`.md`) format to ensure version control, easy editing, and seamless rendering across Zurely's digital touchpoints (including the web platform and the mobile applications).

---

## 📂 Repository Contents

The repository includes, but is not limited to, the following documents:

*   **`privacy-policy.md`**: Outlines how Zurely collects, uses, and protects user data in compliance with Malaysian data protection regulations (such as PDPA).
*   **`terms-of-service.md`**: The legal terms governing the use of the Zurely mobile application and platform.
